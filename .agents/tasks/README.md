# Task records

Task records contain approved scope and implementation evidence.

- Do not create a task plan here before human approval unless file-based planning was explicitly requested.
- Start from ../TASK_TEMPLATE.md.
- Use YYYY-MM-DD-short-task-name.md filenames.
- Record exact approval wording and date.
- Update the same record with implementation outcome, verification, deviations, and remaining work.
- Keep temporary notes and chat transcripts out of this directory.
